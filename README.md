# Generic Stack and Queue Using C++ Templates

Object Oriented Programming Using C++ - Lab Manual, Ex.No 4 (Chennai Institute of Technology).

Template classes `MyStack<T>` and `MyQueue<T>` (fixed-size arrays), benchmarked against `std::stack` and `std::queue` using `<chrono>`.

## Build and run

```
g++ -std=c++17 -O2 main.cpp -o stack_queue
./stack_queue
```

Note: timings vary with the computer, compiler and optimization level.
